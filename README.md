# Web del restaurante [Nombre del restaurante]

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web para un restaurante de Castilla-La Mancha. Su objetivo es presentar el restaurante, mostrar su oferta gastronómica y facilitar a los usuarios el acceso a la información y al formulario de reservas.

La web cuenta con cinco páginas principales, diseñadas siguiendo el manual de identidad visual del restaurante.

## Páginas de la web

- **Inicio:** presenta el restaurante, su tipo de cocina, su propuesta gastronómica y una selección de platos destacados. También incluye enlaces para consultar la carta y realizar reservas.
- **Carta:** muestra los platos del restaurante organizados por categorías, con sus nombres, descripciones, fotografías y precios. Los datos se cargan desde el archivo `data.json` mediante JavaScript y `fetch`.
- **Reservas:** incluye un formulario para introducir el nombre, teléfono, fecha, hora y número de personas. JavaScript valida los datos y muestra un mensaje de confirmación.
- **Nosotros:** explica la historia, la personalidad y la propuesta del restaurante, acercando al usuario a su identidad.
- **Contacto y ubicación:** ofrece información útil para visitar el restaurante, como la dirección, el teléfono, el horario y las indicaciones para llegar.

Todas las páginas comparten un encabezado con la navegación principal y un pie de página con el horario y los enlaces a las redes sociales.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos y adaptación visual.
- **JavaScript:** interactividad, carga de la carta y validación del formulario.
- **JSON:** organización de los datos de los platos.
- **Git y GitHub:** control de versiones y colaboración en equipo.

## Instalación y ejecución

1. Clonar el repositorio de GitHub.
2. Abrir el proyecto en Visual Studio Code.
3. Ejecutar la web mediante Live Server para que funcione correctamente la carga de `data.json`.
